
# Источники задач и контракты
Реализация подсистемы приёма задач в платформе обработки задач. Задачи могут поступать из различных источников, не связанных наследованием, но обязанных реализовывать единый поведенческий контракт.

## Использование
При запуске вас встретит небольшая инструкция, после которой вы можете ввести в терминал какой источник из списка следует обработать. Выход из программы осуществляется путем ввода пользователем строки  "q".

## Установка
### 1. Клонирование
git clone https://github.com/dobri3/lab1_sem_2

### 2. Запуск
python -m src.main

## Устройство работы
task: NamedTuple с полями id:str и payload:str
task_source: протокол с функцией get_tasks(), общей для всех источников
file_source: источник - файл
generator_source: источник - генератор
api_source: источник - имитирование API
api_source_interactive - источник - ввод пользователя, имитированный под API
для уникальности id использовала uuid.uuid4
